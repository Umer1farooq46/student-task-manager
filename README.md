# Student Task Manager

Project status: In Progress

A simple Python console application for managing student tasks.

## Features
- Add tasks
- Display all tasks
- Mark tasks as completed
- Delete tasks
- Validate empty task titles and invalid task IDs

## Requirements
- Python 3.13 or later
- Git

## Setup
Clone the repository:
git clone https://github.com/Umer1farooq46/student-task-manager.git

Navigate into the folder:
cd student-task-manager

## Usage
Run the application:
python main.py

Follow the on-screen menu to manage tasks.

## Tests
Run automated tests:
python -m unittest discover -s tests -v
